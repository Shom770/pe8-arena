# Question 17: keep_positives

File: `solution.ml`

```
keep_positives
Write

keep_positives : int list -> int list

which returns the list of strictly positive elements (greater than 0),
keeping them in their original order. Zero is not positive.

keep_positives [3; -1; 0; 7] = [3; 7]
keep_positives [-2; -5] = []
keep_positives [] = []
```
